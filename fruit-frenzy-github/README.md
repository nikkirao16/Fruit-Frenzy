# Fruit Frenzy Simulator

A Roblox-style clicker game that runs in the browser. Pick fruit, sell it, buy upgrades, unlock rarer orchards, hatch pets and rebirth for permanent boosts.

## How to play

- Click or tap the orchard (or press **Space**) to pick fruit into your basket.
- Press **SELL** (or **S**) to turn your basket into cash.
- **Upgrades** – Auto Clicker, Double Pick, Lucky Hands, Lucky Soil, Golden Touch, Juicier Fruit, Bigger Basket, Full Basket Bonus, Auto Seller, Pet Slots, Egg Luck and Pet Storage.
- **Pets** – hatch eggs for pets that multiply your money. Claim a reward for every new species.
- **Fruits** – see drop chances and claim a reward for every new fruit you find.
- **Rebirth** – reset progress for a permanent money multiplier.
- Close the tabs with ✕, by clicking the open tab again, or with **Esc**.

Progress saves automatically in your browser.

## Run it

It's a single `index.html` file with no build step. Open it in a browser, or host it with GitHub Pages:

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**, set the source to your main branch and the root folder, and save.
3. The game will be live at `https://<your-username>.github.io/<repo-name>/`.
